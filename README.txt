Откройте index.html. Папка assets должна лежать рядом. На хостинг загружайте их вместе.

Логотипы клуба:
assets/collab-header.png — белый на синем, в шапке.
assets/collab-footer.png — синий на светлом, в подвале.
assets/collab-circle.png — запасной круглый вариант, на странице не используется.

Для замены положите новый файл с тем же именем в assets. При изменении формата обновите src в HTML. Атрибуты width и height укажите по исходным размерам нового файла. Отображаемая ширина регулируется переменными --club-header и --club-footer. Изображения сохранены как присланы, включая фон и поля.

Партнёры: assets/hse.png и assets/tbank.jpg. Размер на странице — переменная --partner-logo.
REGISTRATION_URL — ссылка регистрации; CONTACTS — контакты.
